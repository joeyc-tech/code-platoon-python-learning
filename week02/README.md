# Week 2: Python Lists

During Week 2, I practiced creating and modifying Python lists. I also completed a group coding challenge that generates a boarding pass.

## Topics Covered

- Creating lists
- Accessing list elements by index
- Adding elements with `.append()` and `.insert()`
- Adding multiple elements with `.extend()`
- Removing elements with `.pop()` and `.remove()`
- Writing and calling functions
- Returning values from functions
- Collecting information with `input()`
- Building output with f-strings

## Exercises

- `01_days_of_week.py` - Add days to a list
- `02_itinerary.py` - Build and update a travel itinerary
- `03_remove_list_elements.py` - Remove list elements by index and value
- `04_boarding_pass.py` - Create a boarding pass with a function

## Running an Exercise

From the repository folder:

```bash
python3 week02/exercises/01_days_of_week.py
```
