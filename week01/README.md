# Week 1: Python Fundamentals

Week 1 introduced the building blocks of Python. The organized files below make each topic easy to review and run on its own.

## Topics Covered

- Variables and data types
- Printing output
- Functions and return values
- Strings and f-strings
- String methods and slicing
- Integers, floats, math, and booleans

## Files

| File | Contents |
| --- | --- |
| `01_variables_and_types.py` | Basic output, variables, and Python data types |
| `02_functions.py` | Parameters, return values, and reusable functions |
| `03_strings.py` | Concatenation, f-strings, and user input |
| `04_string_methods_and_slicing.py` | Counting, cleaning, replacing, splitting, and slicing strings |
| `05_numbers_and_booleans.py` | Arithmetic, math functions, comparisons, and boolean expressions |
| `hello_world.py` | Original combined class scratchpad, preserved unchanged |
| `week01_notes.md` | A summary of Week 1 lessons |

## Run an Exercise

From the repository folder:

```bash
python3 week01/01_variables_and_types.py
```

The original `hello_world.py` remains available so no Week 1 classwork or history was lost.
